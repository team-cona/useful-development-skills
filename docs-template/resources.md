# Resources

업무에 필요한 정보와 반복해서 사용하는 자료를 빠르게 찾기 위한 인덱스입니다.

## 1. Getting Started | 온보딩

- **[개발 환경 구축 가이드]**
  - 신규 개발 환경을 설정할 때 참고
- **[계정 및 권한 신청]**
  - 업무 시스템에 접근 권한이 필요할 때
- **[프로젝트 및 시스템 소개]**
  - 시스템 구조나 담당 서비스를 파악할 때

## 2. Development | 개발 환경

- **[로컬 개발 환경]**
  - 실행 환경 및 필수 설정
- **[개발 / 테스트 환경 접근]**
  - 환경별 접근 방법과 관련 문서
- **[디버깅 도구 모음]**
  - 자주 사용하는 디버깅 도구와 사용법

## 3. Tools & Devices | 도구 및 장비

- **[모바일 테스트 기기 신청]**
  - 신청 경로, 담당자, 사용 절차
- **[모바일 기기 연결 가이드]**
  - 테스트 기기를 개발 환경에 연결하는 방법
- **[Charles Proxy 설정 가이드]**
  - 네트워크 요청 디버깅을 위한 환경 설정
- **[기타 개발 도구]**
  - 자주 활용하는 도구의 사용법

## 4. Operations | 운영 및 트러블슈팅

- **[로그 및 모니터링 도구]**
  - 문제 발생 시 확인할 위치
- **[자주 발생하는 오류]**
  - 반복적으로 마주치는 문제와 해결 방법
- **[배포 및 운영 절차]**
  - 관련 가이드와 확인해야 할 사항

## 5. Checklists | 체크리스트

- [ ] 새로운 개발 환경을 구성할 때
- [ ] PR을 생성하거나 리뷰할 때
- [ ] 배포 전후 상태를 확인할 때
- [ ] 문제 발생 시 원인을 조사할 때

## Maintenance

- 링크 옆에는 언제 사용하는 자료인지 간단히 설명합니다.
- 정보가 변경되면 기존 문서를 업데이트합니다.
- 직접 작성한 가이드에는 마지막 확인 날짜를 남깁니다.
- 오래되거나 유효하지 않은 링크는 정리합니다.
