# My Workspace:  개인 업무 허브

## 01. Work Log: 작업 일지
주간 기록 · 진행 상황 · 성과 · 다음 할 일

## 02. Learning & Sharing: 스터디/공유
### Quick Notes
짧게 남기는 학습, 발견, 시행착오

### Wiki
팀에 공유할 만한 주제별 심화 문서

## 03. Resources: 업무 리소스
온보딩 · 환경 설정 · 도구 · 업무 매뉴얼 · 유용한 링크

| 구분          | 목적                    | 작성 주기         |
| ----------- | --------------------- | ------------- |
| Work Log    | 무엇을 했는지 추적            | 매일 기록, 주간 페이지 |
| Quick Notes | 새롭게 알게 된 것을 빠르게 축적    | 수시            |
| Wiki        | 재사용하거나 공유할 지식을 정리     | 필요할 때         |
| Resources   | 반복적으로 사용하는 정보에 빠르게 접근 | 필요할 때 갱신      |

작업일지 → 짧은 기록 → 위키 문서 → 리소스로 문서화하기.
